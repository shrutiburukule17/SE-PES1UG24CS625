1. Problem Overview

The **Hospital Bed & ICU Allocation Dashboard** is an emergency room bed management system designed to display real-time ward occupancy, prioritize ICU transfers based on patient triage scores, and support inter-facility ambulance transfer workflows.

Target Stakeholders / Actors

* Triage Nurse
* Hospital Administrator



2. Objectives

The system aims to:

* Monitor real-time hospital ward and ICU bed occupancy.
* Prioritize patients for ICU transfer based on triage severity.
* Manage the ER bed allocation waitlist.
* Track bed status such as Occupied, Cleaning, and Available.
* Support inter-facility ambulance transfer workflows.
